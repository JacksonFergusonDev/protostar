CI Environment Notice & Benchmark Methodology

These measurements track help-command startup and the recipe editor's first frame (including process startup and shutdown) on GitHub Actions Ubuntu runners with Python 3.14, in the checked-out repository. They do not measure a completed scaffold or dependency installation, and are not estimates of local workstation latency. Each point is the mean of 90 Hyperfine executions after 30 warmups. Runner variability and changes to the runner image or project checkout can affect comparisons, so sustained trends are more useful than an isolated increase. The summary compares the latest measurement with up to 100 preceding runs of the same benchmark; this is separate from CI's regression check. CI blocks results above 250% of the preceding recorded result, while historical tracking alerts above 200%. Older wizard measurements remain in the JSON export but are excluded from the recipe-editor chart and its comparisons.
