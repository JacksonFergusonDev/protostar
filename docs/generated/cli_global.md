| Option | Description |
| :--- | :--- |
| `-v, --verbose` | Show debug logs and full tracebacks. |
| `--json` | Print one JSON payload on stdout and never prompt. |
| `--config <path>` | Read global configuration from this file instead of the default location. |
| `--no-config` | Ignore global configuration entirely and use built-in defaults. |
| `--version` | Show the application's version and exit. |
