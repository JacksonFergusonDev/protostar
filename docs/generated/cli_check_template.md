```text
protostar check-template [<source>] [options]
```

| Option | Description |
| :--- | :--- |
| `<source>` | A template directory, a template TOML file, or a URL. Defaults to the current directory. |
| `--strict` | Fail on warnings as well as errors. |
| `--output-format <format>` | text (default) for people, or github for GitHub Actions annotations on the template's files. |
