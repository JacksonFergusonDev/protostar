| Option | Description |
| :--- | :--- |
| *(No args)* | Opens a form for your identity, editor, Python version, and tool defaults, and saves only what changed. Needs an interactive terminal. |
| `--edit` | Opens `config.toml` in your system's default `$EDITOR`, seeding the default template if it is missing. |
| `--reset` | Resets configuration to factory defaults (prompts for confirmation). |
| `-f`, `--force` | Bypasses the confirmation prompt when used with `--reset`. |
